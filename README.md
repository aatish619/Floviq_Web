# Floviq Landing Website

A premium static landing website for Floviq, an AI automation startup helping businesses streamline operations with AI-powered workflows, WhatsApp automation, lead management, customer support, and business process automation.

## Project Files

- `index.html` - Main website markup
- `styles.css` - Responsive visual design, layout, and animations
- `script.js` - Mobile navigation and scroll reveal interactions
- `assets/floviq-logo.png` - Floviq brand logo used in the header, footer, and favicon

## Run Locally

Open `index.html` directly in your browser, or run a small static server:

```bash
python3 -m http.server 5173
```

Then visit:

```text
http://localhost:5173
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Go to [Vercel](https://vercel.com).
3. Choose **Add New Project** and import the repository.
4. Keep the framework preset as **Other** or **Static**.
5. Leave build command and output directory empty.
6. Deploy.

## Deploy to Netlify

1. Push this folder to a GitHub repository.
2. Go to [Netlify](https://www.netlify.com).
3. Choose **Add new site** and import the repository.
4. Leave build command empty.
5. Set publish directory to the project root.
6. Deploy.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch and root folder.
6. Save and wait for the GitHub Pages URL to become available.
